# pi-environment-monitor

Scaffolding stage. The panel is not implemented yet, so there is nothing to
answer from here. Do not describe behaviour this package does not have.

The intended scope, once built: an on-demand panel listing every installed
skill, extension, MCP server, package, theme and prompt template across all
scopes pi reads from, each with its real path on disk and whether it is
currently disabled. Read-only — toggling is a later phase.
